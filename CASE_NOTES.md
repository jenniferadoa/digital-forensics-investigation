# Case Notes

## Case Name
Suspected Data Theft Investigation

## Scenario
An employee is suspected of copying confidential company files before leaving the organisation.

A forensic image of the employee's computer has been collected for investigation.

The purpose of this investigation is to determine whether files were accessed, copied, deleted, or transferred.

## Investigation Questions
1. Were confidential files accessed?
2. Were any files deleted?
3. Was a USB device connected?
4. Was suspicious browser activity identified?
5. What happened and in what order?

## Evidence
- Forensic disk image
- File metadata
- Deleted files
- Browser history
- USB activity
- System timestamps

## Investigation Status
In progress.
